# 🌿 Greenden Website

A beautifully crafted, responsive **e-commerce plant nursery website** built to showcase and sell an array of indoor and outdoor plants. This project focuses on a clean, nature-inspired user experience with seamless visual transitions.

## 🚀 Live Demo
You can view the live project here: **[Insert Your Live Link Here (e.g., GitHub Pages)]**

## ✨ Features
* **Responsive Layout:** Optimized for mobile, tablet, and desktop viewports using Tailwind's utility classes.
* **Modern UI Components:** Styled landing pages, interactive product grids, filter sidebars, and clean navigation menus.
* **Filter & Search Sections:** Visually ready sections for users to search plants and sort by categories.
* **Clean & Semantic Code:** Written in structural HTML5 styled directly with efficient Tailwind CSS utilities.

## 🛠️ Tech Stack
* **HTML5:** Semantic markup structure
* **Tailwind CSS:** Utility-first CSS framework for custom layout styling

## 📦 Installation & Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate to the project folder:**
   ```bash
   cd YOUR-REPO-NAME
   ```

3. **Open the site:**
   Simply launch `index.html` in your favorite web browser. 
   *(Optional: If you are using Tailwind via CLI or a build tool, run `npm install` and your build script first).*
